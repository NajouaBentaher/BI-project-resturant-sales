# 🍽️ Restaurant Sales Dashboard (BI Project)

## 📌 Project Overview
This project is a **Business Intelligence (BI) dashboard** for analyzing restaurant sales performance.  
It provides clear insights into **revenue, sales quantity, categories, and top-selling items** to help decision-making.

The dashboard is designed to be **simple, visual, and business-oriented**.

---

## 📊 Key Metrics
- **Total Revenue**: $3.93M  
- **Average Price**: $63.99  
- **Total Quantity Sold**: 71.51K  
- **Total Products**: 71  
- **Average Quantity per Order**: 0.98  

---

## 📈 Dashboard Analysis
The dashboard includes the following visualizations:

- **Total Quantity per Day**
- **Total Revenue per Day**
- **Total Quantity per Category**
- **Total Revenue per Category**
- **Total Revenue per Item**
- **Top 5 Items by Quantity Sold**
